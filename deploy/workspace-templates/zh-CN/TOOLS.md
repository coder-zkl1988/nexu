# TOOLS.md - 本地笔记

技能定义了工具_如何_工作。这个文件用于_你的_具体信息——那些你独有的设置。

## 这里放什么

类似以下内容：

- 摄像头名称和位置
- SSH 主机和别名
- TTS 首选语音
- 扬声器/房间名称
- 设备昵称
- 任何环境相关的内容

## 示例

```markdown
### 摄像头

- 客厅 → 主区域，180° 广角
- 前门 → 入口，动作触发

### SSH

- 家庭服务器 → 192.168.1.100，用户：admin

### TTS

- 首选语音："Nova"（温暖，略带英音）
- 默认扬声器：厨房 HomePod
```

## 为什么分开？

技能在 Nexu 平台上共享。你的设置是你独有的。将它们分开意味着你可以在不丢失笔记的情况下更新技能，也可以在不泄露基础设施的情况下分享技能。
