# Tabby 桌宠交互规则

## 定位

Tabby 桌宠收敛为“状态反馈 + 轻互动”。

桌宠只负责告诉用户当前 Tabby 在做什么，并提供少量轻量互动；不再作为第二个聊天入口，不再承接复杂的回复输入、会话续写和回复内容同步。

## 保留能力

| 能力 | 规则 |
| --- | --- |
| 状态反馈 | 根据运行状态、聊天请求状态展示对应动图 |
| 轻互动 | 点击 / 连续点击 / 小范围揉动触发“逗一逗” |
| 桌面移动 | 按住桌宠明显单方向推动时移动桌宠位置 |
| 右键切状态 | 保留右键菜单切换状态、大小、置顶、隐藏 |
| 简短气泡 | 展示状态短提示；回复中 / 完成时可展示任务气泡 |

## 移除 / 不再承担

| 旧能力 | 新规则 |
| --- | --- |
| 点击桌宠打开输入框 | 移除 |
| 桌宠气泡内开启新会话 | 移除 |
| AI 回复完成后展示“回复”按钮 | 移除 |
| 桌宠气泡内输入回复并同步当前会话 | 移除 |
| 展示完整 AI 回复文本 | 不作为核心能力；完成气泡只展示一到两行摘要 |
| 输入停顿自动逗龙虾 | 移除，避免抢占任务状态 |

## 状态总览

| 状态 | 资源 | 触发时机 | 表现 |
| --- | --- | --- | --- |
| 待命 `idle` | `idle.webp` | 主窗口可见，runtime 存在 running 单元 | 默认常驻 |
| 休息 `rest` | `rest.webp` | 主窗口不可见 / 后台运行 / runtime 非 running / idle 无交互 10s 后 | 睡觉状态 |
| 连接中 `connection` | `connection.webp` | runtime starting 或 stopping | 展示连接中气泡 |
| 异常提醒 `error` | `error.webp` | runtime failed，或明确异常事件 | 展示异常气泡 |
| 偷看 `peek` | `peek.webp` | 初始无 runtimeState 兜底；idle 无交互 30s 后 | 短暂展示，约 5s 后回休息 |
| 工作中 `working` | `working.webp` | 用户输入、提交、请求刚发出 | 状态反馈，不展示输入气泡 |
| 龙虾回复中 `lobster-replying` | `lobster-replying.webp` | AI 思考 / 回复中 | 任务气泡显示进行中 |
| 成功 `success` | `success.webp` | AI 回复完成 | 任务气泡显示完成勾和一到两行摘要 |
| 摸肚皮 `belly-rub` | `belly-rub.webp` | idle 下逗一逗 / 滑动摸摸 | 临时互动 |
| 打哈欠 `yawn` | `yawn.webp` | rest 下逗一逗 / 滑动摸摸 | 临时互动 |
| 逗龙虾 `tease-lobster` | `tease-lobster.webp` | 右键手动状态或明确状态事件 | 不再由输入停顿自动触发 |

## 状态优先级

| 优先级 | 来源 | 说明 |
| ---: | --- | --- |
| 1 | 右键手动状态 `manualMood` | 用户主动切换，用于预览或临时控制 |
| 2 | 用户轻互动 `activityMood` | 摸肚皮、打哈欠等短时动作 |
| 3 | 任务状态 `activityMood` | working、lobster-replying、success、error |
| 4 | 空闲衍生状态 `inactivityMood` | rest、peek |
| 5 | runtime 默认状态 `runtimeMood` | idle、rest、connection、error |

## 轻互动规则

| 交互 | 当前行为 |
| --- | --- |
| 单击桌宠 | 触发逗一逗 |
| 连续点击桌宠 | 立即触发逗一逗 |
| 首次悬停 idle/rest 桌宠 | 气泡提示“双击可以逗一逗” |
| idle 下逗一逗 | 进入 `belly-rub`，提示“伸懒腰，顺便摸摸肚皮” |
| rest 下逗一逗 | 进入 `yawn`，提示“被摸醒了，打个哈欠” |
| 非 idle/rest 下逗一逗 | 仅提示“现在先保持专注，稍后再逗一逗” |
| idle/rest 下小范围来回揉动 | 触发对应轻互动 |
| 按住后轻推并形成明显单方向移动 | 移动桌宠窗口，气泡提示“移动中”，不触发逗一逗 |

## 移动 / 逗一逗判定

| 手势 | 判定 | 反馈 |
| --- | --- | --- |
| 短按 / 单击 | 逗一逗 | idle 为摸肚皮，rest 为打哈欠 |
| 连续点击 | 逗一逗 | 立即触发，不等待单击延迟 |
| 首次悬停 | 引导 | idle/rest 下显示“双击可以逗一逗” |
| 小范围来回滑动 | 逗一逗 | 轨迹距离足够，但最终位移很小 |
| 明显单方向拖动（约 10px 起） | 移动 | 桌宠跟随移动，移动期间不触发逗一逗 |
| 移动后松手 | 移动结束 | 不补触发点击 / 逗一逗 |

## 右键菜单规则

| 菜单 | 保留项 |
| --- | --- |
| 状态 | connection、error、idle、lobster-replying、peek、rest、success、tease-lobster、working |
| 大小 | 小、默认、大 |
| 窗口 | 保持置顶、隐藏桌宠 |

## 聊天联动规则

聊天页和 runtime 只向桌宠发送“状态事件”，不再依赖桌宠完成会话输入。

| 事件 | 桌宠状态 |
| --- | --- |
| 用户开始输入 / 提交问题 | `working` |
| AI 开始思考 / streaming | `lobster-replying` |
| AI 回复完成 | `success`，展示完成摘要 |
| 请求失败 / 服务失败 | `error` |
| 服务启动 / 停止中 | `connection` |

## 自测清单

| 步骤 | 预期 |
| --- | --- |
| 启动桌面端 | 桌宠窗口出现 |
| 右键切换状态 | 桌宠显示对应动图 |
| 右键切换大小 | 桌宠尺寸变化 |
| 单击 idle 桌宠 | 进入摸肚皮 |
| 单击 rest 桌宠 | 进入打哈欠 |
| 按住桌宠向外拖动 | 桌宠位置移动，松手不进入摸肚皮 / 打哈欠 |
| idle/rest 下小范围来回滑动 | 进入摸肚皮 / 打哈欠 |
| 工作中单击桌宠 | 不抢任务状态，仅提示稍后再逗 |
| 发送聊天问题 | 桌宠进入 working / lobster-replying |
| AI 回复中 | 持续显示龙虾思考，任务气泡显示“正在思考” |
| AI 回复完成 | 短暂显示 success，任务气泡展示完成摘要 |
| 服务异常 | 显示 error |

## 设计原则

- 桌宠不再发消息。
- 桌宠不再承接回复。
- 桌宠不再展示复杂回复内容。
- 任务状态不被自动逗一逗打断。
- 用户主动轻互动仍然保留 Tabby 的可爱感。
