# 无限画布能力对齐迁移计划（2026-07-06）

## 背景

侧栏无限画布（design doc `2026-07-03-infinite-canvas-sidebar.md`，已到 v2.2）对参考工程 `~/workspace/infinite-canvas` 做了全量功能清点（45 次文件检索，证据到 file:line），发现约 **22 项特色能力未迁移**。用户决定：**全部迁移**。本计划把它们编排为 4 个 Wave，每个 Wave 结束都是可验收、可发布的完整状态。

**硬约束（全程有效）**
- 参考工程是 AGPL —— **只借鉴范式，零代码复制**（既有惯例，每处新交互注明对齐点）。
- **不新增依赖**：持久化用原生 IndexedDB API 手写；裁剪/拆分用原生 canvas API；无 zustand/idb/图像库。
- 每个 Wave：web 测试 + tsc + lint 全绿；涉 API 的先 `pnpm generate-types`；设计文档追加落地记录。
- 后端能力缺位的生成类功能，一律走 **S7 已验证模式**：通道先行 + 合同消息 + `UNAVAILABLE` 快速失败（tabby-image 当时就是这样等来的）。

**明确的适配性裁剪（不照搬的部分）**
| 参考工程原样 | 我们的适配 | 理由 |
|---|---|---|
| 独立 WS Agent 面板（127.0.0.1:17371） | 不迁移面板；op 协议由**对话流**驱动（S8） | 我们是 chat-first，对话即 agent 入口 |
| 画布内明暗主题开关 | 跟随 App 全局主题 | 避免双主题源 |
| 生成按钮显示算力消耗 | 不显示 | 本地/云账号无 credit 概念 |
| 多项目路由 `/canvas/[id]` | 收敛为工具栏「画布方案」切换器（命名画布） | 画布是侧栏工作台，不是独立页面 |

## Wave 1 —— 地基：持久化 + 手感补全（纯前端，无后端依赖）

> 目标：画布从「易碎演示」变成「可靠工作台」。持久化是其余一切的前提。

| # | 项 | 落地要点 | 验收 |
|---|---|---|---|
| 1.1 | **画布内容持久化** | 手写 IndexedDB 薄层（~80 行，`nexu-canvas` DB）：nodes+connections 自动保存（emit 去抖 ≥500ms）；a2ui 节点存框架（载荷是运行时闭包，重开自恢复，与现状「内容已过期」占位一致）；team-step 节点全量存（挂载即重新轮询看板）。localStorage 视口持久化保留 | 加节点→刷新页面→节点还在；配额/私隐模式降级不炸 |
| 1.2 | 文件拖放进画布 | drop 位置换算 world 坐标建节点；图/视频/音频按 MIME 分型 | 拖 3 类文件落点正确 |
| 1.3 | 系统剪贴板粘贴 | paste 事件：image blob→dataURL 图节点；文本→文本节点；落画布中心 | 截图 Cmd+V 成图节点 |
| 1.4 | 节点复制/粘贴/Duplicate | Cmd+C/V + 右键 Duplicate；保留选区内部连线；偏移 36px；本地剪贴板优先于系统剪贴板 | 复制两个相连节点→粘贴后连线保留 |
| 1.5 | 右键菜单 | 节点：Duplicate/删除；连线：删除；背景：粘贴到此处 | 三处菜单可用，Esc 关闭 |
| 1.6 | 四角缩放 + 宽高比锁定 | 4 角隐形热区（28px，nwse/nesw 光标）；从上/左拉时对角固定（position 同步补偿）；图/视频默认锁比例（naturalWidth/Height），悬停工具栏（W3 前先放头部小锁钮）切自由缩放 | 四角均可拉；锁比例图片不变形 |
| 1.7 | 空格/中键平移 + 缩放范围放宽 | Space 按住转平移光标；button===1 平移；缩放 clamp 0.25–2 → **0.05–5**（a2ui 重节点若极端缩放卡顿，后续再收） | 空格拖动平移；5% 能看全大画布 |
| 1.8 | 导出/导入 UI 入口 | 工具栏两个按钮：导出下载 JSON（媒体已是 dataURL 内嵌）、导入文件选择合并 | 导出→清空→导入还原 |
| 1.9 | 连线落空白→建节点菜单 | 拖连线松空白处弹小菜单（文本/图片/视频/音频/Config*），建节点并自动连线（*Config 到 W2 才有，先四类） | 拖线落空白→选图片→新节点已连 |

**Wave 1 交付判定**：以上 9 项 + 新增单测（持久化 round-trip、复制粘贴连线保留、锁比缩放几何）+ 桌面端真机验收。

## Wave 2 —— 生成管线泛化（影音创作主线）

> 目标：把「连线」从视觉升级为**数据流语义**，生成能力从图片扩展到视频/音频，节点具备异步任务状态。这是「影音创作 tab」的地基。

| # | 项 | 落地要点 | 验收 |
|---|---|---|---|
| 2.1 | **连线=生成输入**通用语义 | 新建 `resource-references.ts`：`collectUpstream(nodeId)` 沿入边收集上游资源（text→提示词上下文、image→参考图、audio/video→参考媒体）；现有 image→XHS 喂图改为该机制的一个 effect | 单测：链式/分叉上游收集正确 |
| 2.2 | 节点异步状态模型 | `metadata.task = { status: idle/generating/success/error, error? }`；生成中节点显示参考风格 spinner（转圈 + 「生成中」字距标签）；失败显示错误 + 重试按钮 | 断网生成→error+重试可用 |
| 2.3 | 每节点提示词面板 | 选中可生成节点（image/video/audio/Config）下方浮出面板：提示词框 + **@引用**已连接上游（自研 mention 下拉，↑↓/Enter/Esc）+ 参数区 | @ 出候选、引用标签高亮 |
| 2.4 | Config 节点 | 新节点类型：模式（图/视频/音频）+ 模型 + 比例/数量/时长；显示上游输入汇总片（提示词/参考图 N）；「生成」按钮把汇总投给对应通道 | 文本+图 连入 Config→汇总片正确 |
| 2.5 | 生图通道升级 | `POST /media/generate-image` 增加可选 `referenceImages`（servable path 列表）+ `count`；合同消息带参考图路径（tabby-image 是否支持参考图需实测，不支持则合同降级为纯提示词并注明） | 既有 S7 测试不回归；带参考图请求 200 |
| 2.6 | 视频/音频生成通道 | `POST /media/generate-video` / `generate-audio`（S7 同构：utility lane + 合同 + 轮询 + 路径校验）；**UNAVAILABLE 快速失败先行**，等官方 skill 落地即点亮（复刻 tabby-image 剧本）；参数：视频时长/分辨率、音频音色/语速 | 通道 502 语义正确；skill 就位后真机再验 |
| 2.7 | 批量图组 | `count>1` → 生成 N 子节点扇形收纳（batchRootId/childIds/expanded/primary）；展开/收起动画、设主图 | 4 张一组收放正常、主图可换 |

**Wave 2 交付判定**：连线喂参考图生图真机通（tabby-image 支持则全通，不支持则纯提示词通 + 参考图链路单测通）；controller 测试新增通道全绿。

## 排期与风险

- **节奏**：W1 一个工作单元（纯前端、无未知数）→ W2 一到两个（риск：tabby-image 参考图支持、视频/音频 skill 时间表不受我们控制，UNAVAILABLE 先行消解）→ W3 一到两个 → W4 两个（S8 单独占一个）。
- **顺序不可倒**:W2 依赖 W1 的持久化（生成中状态刷新不能丢）；W3 依赖 W2 的状态模型与通道；S8 依赖前三波的完整 op 面。
- **性能红线**：v2.2 的交互契约（rAF 合帧/memo 隔离/translate3d/select-none）是所有新增交互的基线,新功能不得引入逐帧 store 全量重渲；0.05 极限缩放若 a2ui 节点掉帧,按节点类型做 LOD（缩略占位）。
- **测试基线**：每 Wave 后 web 全套 + controller 全套（涉后端时）+ 真机验收截图记入设计文档。
